# Ware

Ware — настольный музыкальный плеер для YouTube, YouTube Music, SoundCloud и локальных аудиофайлов. Приложение создано на Electron и использует локальный сервер для работы с медиатекой и онлайн-источниками.

## Возможности

- Поиск и воспроизведение музыки из онлайн-источников, работа с локальными файлами и офлайн-медиатекой.
- Избранное, плейлисты, история, очередь воспроизведения, страницы исполнителей и альбомов, рекомендации.
- Импорт плейлистов из Spotify и Apple Music; подключение Spotify через OAuth.
- Тексты песен, синхронизированная подсветка, перевод и собственные тексты.
- Эквалайзер, аудиоэффекты, регулировка скорости и тона, таймер сна.
- Настройка внешнего вида, визуализатор, пользовательские CSS-темы и JavaScript-плагины.
- Discord Rich Presence, управление медиа-клавишами, работа в системном трее и обновления через GitHub Releases.

Доступность онлайн-функций зависит от сети и сторонних сервисов. Используйте их с соблюдением применимых правил и авторских прав.

## Установка

Готовые сборки, если они доступны для вашей платформы, можно скачать на [странице релизов](https://github.com/peaseee/Ware_player/releases).

### Запуск из исходного кода

Понадобятся Git, Node.js и npm, а также графическое окружение для Electron.

```bash
git clone https://github.com/peaseee/Ware_player.git
cd Ware_player
npm ci
npm start
```

При первом запуске откроется мастер настройки. Для онлайн-воспроизведения и некоторых операций с аудио нужны **yt-dlp** и **ffmpeg**. Ware умеет искать их в `PATH` и предлагает установку недостающих инструментов. Бинарники из папки `bin/` не входят в репозиторий. На macOS автоматическая загрузка ffmpeg не предусмотрена: установите его отдельно, например через пакетный менеджер.

Для поиска и потокового воспроизведения необходимо подключение к интернету. Интерфейс также загружает шрифты из Google Fonts.

## Сборка

```bash
npm run dist
```

Сборка выполняется с помощью `electron-builder`, результат помещается в `dist/`. В конфигурации указаны цели: Windows x64 (NSIS), Linux x64 (AppImage), macOS x64 и arm64 (DMG и ZIP). Доступность кросс-сборки зависит от ОС и установленных инструментов.

**Примечание:** в текущем репозитории отсутствуют файлы иконок `build/icon.png` и `assets/icon.png`, на которые ссылается конфигурация сборки. Перед упаковкой соответствующих платформ необходимо добавить эти ресурсы или изменить настройки иконок в `package.json`. Бинарники yt-dlp и ffmpeg также не включены в чистый клон.

## Текст песни в терминале

Когда Ware запущен, открыть поток текущего текста в терминале можно из каталога проекта:

```bash
node cli.js lyrics
```

Выход — `Ctrl+C`. Если команда `ware` установлена и доступна в `PATH`, можно также использовать `ware lyrics`.

## Данные пользователя

По умолчанию данные Ware хранятся в следующих каталогах:

| Система | Каталог |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Ware` |
| macOS | `~/Library/Application Support/Ware` |
| Linux | `~/.cache/ware` |

Путь к данным можно изменить в настройках или через переменную окружения `WARE_DATA_DIR`. На Linux конфигурация расположена отдельно: в `$XDG_CONFIG_HOME/ware` или `~/.config/ware`.

Плагины выполняют JavaScript-код внутри приложения — устанавливайте их только из источников, которым доверяете.

## Структура проекта

- `main.js` и `preload.js` — процесс Electron и мост к интерфейсу.
- `server.js` — локальный HTTP-сервер и API.
- `index.html`, `styles.css`, `app.js` — интерфейс и логика плеера.
- `audio-engine.js` — обработка звука и эффекты.
- `themes.js`, `plugins.js` — пользовательские темы и плагины.
- `tools.js` — установка внешних инструментов.
- `platform.js` — пути к данным и поиск бинарников.
- `cli.js` — вывод текста песни в терминале.

Скрипт `npm test` запускает стандартный тестовый раннер Node.js; на данный момент тесты в репозитории отсутствуют.
